# Ursu Bau GmbH

> Bau, Renovierung & Reinigung in der Schweiz

Website for Ursu Bau GmbH – renovation, construction and cleaning services in Zürich, Solothurn, Bern and Aargau. Built with React, TypeScript, GSAP animations, and smooth scrolling.

## 🌟 Features

- **Smooth Scroll Experience**: Powered by Lenis for buttery-smooth scrolling
- **Custom Animations**: GSAP-driven parallax effects, card stacking, and reveal animations
- **Custom Cursor**: Interactive cursor that follows user movement
- **Responsive Design**: Fully responsive across all devices
- **Modern Tech Stack**: Built with React 19, TypeScript, and Vite

## 🛠️ Tech Stack

- **React** 19.2.4
- **TypeScript** 5.8.2
- **Vite** 6.2.0
- **GSAP** 3.14.2 (animations)
- **Lenis** 1.0.42 (smooth scrolling)
- **Lucide React** (icons)
- **Tailwind CSS** (styling)

## 📦 Installation

1. Clone the repository:
```bash
git clone git@github.com:alwaysriccardo/ursubau.git
cd ursubau
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

The app will open at `http://localhost:3000`

## 🚀 Build & Deploy

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
